# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 2.0.x | Yes |
| 1.x | No — MQTT 3.1.1 line, superseded by 2.0 |

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/enesdurmus/mqtt-spring-boot-starter/security/advisories/new),
not as a public issue.

Please include the affected version, a description of the impact and, if possible, a minimal
reproduction. You can expect an initial response within a week, and a fix or a decision with a
rationale before any public disclosure.
